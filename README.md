# Webby
Welcome to the official user manual for Webby, an AI-enhanced web scraping system. Webby leverages Large Language Models (LLMs) to automate the collection and structuring of web data, making dataset creation faster and more intuitive than ever before.

1. System Overview
Webby is designed to bridge the gap between raw web content and structured data. Unlike traditional scrapers that require complex coding or CSS selectors, Webby uses AI to understand your intent and format data based on natural language prompts.

Core Functionalities
Automated Web Crawling: Fetches raw HTML and content from target URLs.

AI-Powered Extraction: Uses LLMs to parse, clean, and structure data.

Job Management: A dashboard to track, view, and organize multiple scraping tasks.

Multi-Format Export: Supports CSV, Excel, and JSON formats for seamless integration into your workflow.

2. Step-by-Step User Guide
Step 1: Accessing the Platform
Sign Up / Login: Navigate to the landing page. If you are a new user, click Sign Up to create an account. Existing users can enter their credentials to access the Dashboard.

Dashboard: This is your command center where you can see a summary of all your scraping activities and job statuses.

Step 2: Initiating a New Job
Navigate to the New Job section in the sidebar or top menu.

Job Name: Enter a unique name for your project (e.g., "E-commerce Price Research").

Target URL: Paste the full web address of the site you wish to scrape.

Create Job: Click the button to start the initial fetch. The system will crawl the page content.

Step 3: Verifying Content
Once the job status shows "Done," click View Detail.

Review the captured content to ensure the system successfully reached the target data.

Step 4: AI Content Extraction
Navigate to the Extract Content tab.

Input Prompt: This is where you talk to the AI. Enter a specific instruction, such as: "Extract all product names, prices, and star ratings into a table."

Extract Information: Click the button. The AI will process the raw data and present the structured results directly below the input field for your review.

Step 5: Exporting Your Dataset
Go to the Export section.

Select Job: Choose the job you just completed from the dropdown menu.

Select Format: Choose between three industry-standard formats:

CSV: Best for large datasets and basic spreadsheets.

Excel: Best for data analysis and visualization.

JSON: Best for developers and software integration.

Download: Click export to save the file to your device.

3. Best Practices for Extraction Prompts
To get the best results from the AI-Enhanced extraction, follow these tips:

Be Specific: Instead of saying "get info," say "Extract the article title, author name, and date published."

Define Types: Mention if you want specific formats, like "Ensure all prices include the currency symbol."

Keep it Clean: If the page is cluttered, tell the AI to "Ignore navigation menus and footers."

Note: Webby is designed for efficiency. By combining traditional scraping with LLM intelligence, it eliminates the need for manual data cleaning.
